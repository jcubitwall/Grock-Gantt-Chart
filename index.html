Units & Generate

Tell it what you're building — pod size, interior complexity, quantity — then add it to the chart. Each pod's own task durations come from Task Templates.

Group — give two or more pods the same Group name and they combine into ONE merged section on the chart: matching tasks (Box Construction, Wiring, etc.) become a single bar covering all of them, with duration scaled to the group's combined quantity, instead of separate bars per pod. Leave Group blank to keep a pod on its own.
+ Add to Chart appends a pod (or its whole group) to your project alongside whatever's already there — it does not touch anything already in the chart, so you build up one combined project piece by piece. Change a pod's group/size/complexity/qty after it's in the chart? Use ↻ Update to swap in the new task list for that pod's group only.
Check as many interior-complexity boxes as apply to a pod. Task durations, checklists, and which tasks apply to which complexity are all set in Task Templates.

Task Templates

This is the library "Add to Chart" pulls from — the source of truth for how long each task takes per pod size, which interior type it applies to, and its completion checklist.

Applies to: all = happens on every pod. Space / Bedroom/Living / Bath/Kitchen = only included for pods with that box checked.
Base days are the duration for each pod size at qty 1 — fractions like 0.25 or 0.5 are fine for quick tasks. +Per extra unit adds days for each additional pod beyond the first in that unit line, and also accepts fractions.
A single pod's task pill is never shorter than 1 full day even if its time comes out under that (e.g. a lone 0.5-day task still fills the day) — but when several pods are grouped together, their fractional days for the same task ADD UP first and only then round to whole days. So two pods each needing 0.5 day (set base 0.5 and +Per extra unit 0.5) combine into one single 1-day pill instead of two separate full days — the timeline reflects the real combined effort instead of exaggerating it.
Order — use the ▲▼ buttons to move a task earlier or later in the sequence. Tasks moved to the same spot run in parallel and the next task waits for the slowest of them.
Lead / Aids are just a starting point for newly generated tasks — anyone with editing rights can still change them per task afterward.
Checklists aren't set here — add or edit a task's checklist directly on its own pill once it's on the chart.
